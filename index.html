Noonmark.

Privacy policy. Effective 15 October 2026.

The short version

Noonmark collects no personal data. Not little data, not anonymous data, not metadata. There is no account, no server, no analytics, no advertising, and no third-party tracker inside the app.

Where your tasks live

Everything you enter is stored in a private database on your device alone. The release build of Noonmark makes no network requests.

Exports

You can export your tasks as a plain JSON file and import them on another device. That file is yours. It never passes through us, because there is no us to pass through.

Permissions

Noonmark requests no runtime permissions on Android. Sharing an export uses the Android system share sheet, and importing uses the system file picker. Both are handled by your device, not by us.

Children

Noonmark is not directed at children and collects nothing from anyone of any age.

Changes

If this policy ever changes, the new text will appear on this page with a new date before the change ships.
